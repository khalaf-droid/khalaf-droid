## 🧠 Engineering Profile

<img align="right" width="280" src="https://user-images.githubusercontent.com/74038190/212284158-e840e285-664b-44d7-b79b-e264b5e54825.gif">

I'm a **Full-Stack MEAN Developer** who treats software the way an architect treats a building — the interface is only the facade; what matters is the structure underneath.

**How I think about engineering:**

- 🏗️ **Architecture first** — before writing a controller, I design the data model, the API contract, and the failure modes.
- 🔐 **Security is not a feature, it's a default** — validation, sanitization, and hashing aren't "nice to have," they ship with v1.
- ⚙️ **Systems over scripts** — I design for the 10th feature request, not just the 1st.
- 📐 **Product-aware engineering** — I care about *why* a feature exists before I care about *how* to build it.
- 🔁 **Iteration with discipline** — clean commits, documented decisions, and code that a teammate can read without asking me.

> Currently translating this mindset into two real products: **RideHub** (a MEAN Stack ride-hailing PWA for Egypt/MENA) and a **YouTube-inspired video platform** built on Angular 20.

## ⚡ Engineering Principles

<div align="center">

| Principle | Practice |
|:---|:---|
| ✅ **Clean Architecture** | Controllers · Services · Models · Routes · Utils |
| ✅ **SOLID & DRY** | Maintainable, testable, decoupled modules |
| ✅ **RESTful API Design** | Predictable resources, consistent status codes |
| ✅ **Security First** | Joi/Validator input validation, XSS protection, Argon2/Bcrypt hashing |
| ✅ **Auth & Access** | JWT-based auth, Role-Based Access Control (RBAC) |
| ✅ **Global Error Handling** | Centralized error middleware, no silent failures |
| ✅ **Performance** | Lean Mongoose queries, indexing, minimal payloads |
| ✅ **Logging & Observability** | Structured logs for real debugging, not `console.log` |
| ✅ **Scalability** | Stateless services, horizontally-scalable design |

</div>
